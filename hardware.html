Hardware Projects

Web-Controlled Stepper Motor (Zybo Z7-10)

Fixed and extended a stepper motor controller running FreeRTOS and the lwIP TCP/IP stack on a Zybo Z7-10 board. Built an opto-isolated driver circuit using an LTV-847, served motor parameters over a lightweight HTTP/JSON web server with input validation, added stepping modes, LED status feedback and an emergency stop, and controlled it remotely from a Python script.

Skills

  • FreeRTOS and embedded C
  • TCP/IP networking with lwIP, HTTP and JSON
  • Opto-isolated circuit design and breadboarding
  • Stepper motor control
  • Input validation and safety features

32-bit RISC-V CPU (Controller and Datapath)

Designed and verified single-cycle and multi-cycle 32-bit RISC-V CPUs. Completed the core RTL (immediate extend, data memory, register file, ALU), added BEQ branching, built the multi-cycle control FSM with SLL, SRL, ADDI and a custom HALT instruction, and validated it with a custom assembly program in simulation.

Skills

  • RTL design and digital logic
  • CPU microarchitecture and FSM controller design
  • RISC-V instruction set and assembly
  • Simulation and waveform verification
